# CloudGravity Releases

Official Windows Setup (CloudGravity-Setup-*-win-x64.exe) and signed Android APK (CloudGravity-Android-*.apk) distributions for **CloudGravity** (LAN-only low-latency Windows -> Android game and desktop streaming).

Every binary asset is accompanied by a .sha256 checksum verified automatically by the CloudGravity Windows & Android in-app updaters before installation.
